01

What is Java?

জাভা হলো একটি high-level, object-oriented প্রোগ্রামিং ভাষা। এটি ক্লাস ও অবজেক্টের উপর ভিত্তি করে তৈরি, তাই একে object-oriented programming (OOP) ভাষা বলা হয়।

Java is a high-level, object-oriented programming language. It's built around classes and objects, and supports the four core OOP principles:

01

Inheritance

বৈশিষ্ট্য উত্তরাধিকার সূত্রে পাওয়া

02

Abstraction

অপ্রয়োজনীয় তথ্য লুকানো

03

Encapsulation

ডেটা ও কোড এক ইউনিটে বাঁধা

04

Polymorphism

এক নাম, ভিন্ন রূপ

Golden Rules of a Java Program

1. Every application begins with a class, and the class name must match the file name.
2. Every line of code that runs must be inside a class. Class names start with an uppercase letter.
3. Java is case-sensitive — myClass and Myclass are treated as completely different names.
4. The main() method is required in every Java program — this is where execution starts.
Main.java — Hello World
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}

Data Types & Identifiers

Java-তে ডেটা টাইপ দুই ভাগে ভাগ করা যায়: primitive (সরাসরি মান রাখে) আর non-primitive (রেফারেন্স রাখে)।

"7" vs '7' vs 7

LiteralTypeMeaning
"7"StringSequence of characters
'7'charSingle character
7intNumeric integer value

Primitive Types

  • byte, short, int, long, float, double, char, boolean
  • Stores value directly inside memory stack
  • Fixed size, faster processing

Non-Primitive Types

  • String, Array, Class, Object, Interface
  • Stores a memory reference pointer
  • Size depends on object configuration

Variables in Java

ভ্যারিয়েবল কোথায় ঘোষণা (declare) করা হচ্ছে তার উপর ভিত্তি করে তিন প্রকার: Local, Instance, আর Static।

Local Variable

Declared inside a method/block. Block scope protection wrapper.

Instance Variable

Declared inside class, outside methods. Every object gets its own copy.

Static Variable

Declared with static keyword. Shared universally across all objects.

Control Statements (Selection & Iteration)

জাভায় শর্ত সাপেক্ষে কোড চালানো (if-else, switch) এবং কোনো কাজ বারবার করার জন্য লুপ (for, while, do-while) ব্যবহার করা হয়।

Conditional (if-else) Structure

ControlDemo.java
public class ControlDemo {
    public static void main(String[] args) {
        int score = 85;
        
        if (score >= 90) {
          System.out.println("Excellent!");
        } else if (score >= 80) {
          System.out.println("Good Job!");
        } else {
          System.out.println("Keep trying!");
        }
    }
}

Loops (for loop structure)

LoopDemo.java
public class LoopDemo {
    public static void main(String[] args) {
        // Prints 0 to 4
        for (int i = 0; i < 5; i++) {
            System.out.println("Count: " + i);
        }
    }
}

Taking User Input (Scanner Class)

কনসোল থেকে ইউজারের ইনপুট ডাটা রিড করার জন্য জাভায় java.util.Scanner প্যাকেজ ইমপোর্ট করে ব্যবহার করা হয়।

Common Scanner Methods:
• nextInt() — Integer টাইপ ডাটা ইনপুট নেয়।
• nextDouble() — Double টাইপ দশমিক ডাটা ইনপুট নেয়।
• next() — স্পেস ছাড়া একটি সিঙ্গেল ডাব্লিউ (Word) ইনপুট নেয়।
• nextLine() — স্পেসসহ পুরো এক লাইন টেক্সট ইনপুট নেয়।
InputDemo.java
import java.util.Scanner;

public class InputDemo {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        
        System.out.print("Enter an integer: ");
        int number = input.nextInt();
        
        System.out.println("You entered: " + number);
    }
}

Arrays in Java

অ্যারে হলো একই ডেটা টাইপের অনেকগুলো উপাদানের একটি নির্দিষ্ট সাইজের সিকোয়েন্সিয়াল কালেকশন। এর ইনডেক্সিং শুরু হয় 0 থেকে।

ArrayDemo.java
public class ArrayDemo {
    public static void main(String[] args) {
        // Declaration and initialization
        int[] numbers = {10, 20, 30, 40, 50};
        
        // Printing index 0
        System.out.println("First Element: " + numbers[0]);
        
        // Iterating via length property
        for (int i = 0; i < numbers.length; i++) {
            System.out.print(numbers[i] + " ");
        }
    }
}

Methods & Method Overloading

একই ক্লাসে একই নামের একাধিক মেথড থাকলে, কিন্তু প্যারামিটার আলাদা হলে, তাকে method overloading বলে। এতে প্রোগ্রামের readability বাড়ে।

OverloadDemo.java
public class OverloadDemo {
    public void sum(int a, int b) {
        System.out.println(a + b);
    }
    public void sum(double a, double b) {
        System.out.println(a + b);
    }
}

Constructors

Constructor একটি বিশেষ মেথড যা অবজেক্ট তৈরি হওয়ার সময় স্বয়ংক্রিয়ভাবে কল হয়ে অবজেক্টকে initialize করে। এর কোনো রিটার্ন টাইপ থাকে না।

Box.java
public class Box {
    int height; int width;

    // Default Constructor
    public Box() {
        this.height = 10; this.width = 15;
    }

    // Parameterized Constructor
    public Box(int h, int w) {
        this.height = h; this.width = w;
    }
}

The `super` Keyword

super কিওয়ার্ড দিয়ে চাইল্ড ক্লাস থেকে সরাসরি তার immediate parent (ঠিক উপরের অভিভাবক) ক্লাসের প্রোপার্টি অ্যাক্সেস করা যায়।

Three Key Uses of super:
1. super.variableName — Parent class-এর instance variable-কে নির্দেশ করতে।
2. super.methodName() — Parent class-এর মেথডকে ডাকতে।
3. super() — Parent class-এর constructor-কে কল করতে।
Vehicle.java — Using super Keyword
class Vehicle {
    int speed = 50;
    public void display() {
        System.out.println("Hello parent vehicle!");
    }
}

class Car extends Vehicle {
    int speed = 100;
    
    @Override
    public void display() {
      System.out.println("Hello Rakin");
        System.out.println(super.speed);   // Access immediate parent variable (50)
        System.out.println(speed);         // Access child variable (100)
        super.display();                   // Invoke parent method
    }
    
    public static void main(String[] args) {
        Car obj = new Car();
        obj.display();
    }
}

Encapsulation

ভ্যারিয়েবল private রেখে, পাবলিক set ও get মেথড দিয়ে সেই ভ্যারিয়েবলের মান পড়া/লেখার নিয়মকে Encapsulation বলে。

Person.java
public class Person {
    private String name; // Private variable

    // setter
    public void setName(String name) {
        this.name = name;
    }
    // getter
    public String getName() {
        return name;
    }
}
