What is Java?

জাভা হলো একটি high-level, object-oriented প্রোগ্রামিং ভাষা। এটি ক্লাস ও অবজেক্টের উপর ভিত্তি করে তৈরি, তাই একে object-oriented programming (OOP) ভাষা বলা হয়।

Java is a high-level, object-oriented programming language. It's called "object-oriented" because it's built around classes and objects, and supports the four core OOP principles:

01

Inheritance

বৈশিষ্ট্য উত্তরাধিকার সূত্রে পাওয়া

02

Abstraction

অপ্রয়োজনীয় তথ্য লুকানো

03

Encapsulation

ডেটা ও কোড এক ইউনিটে বাঁধা

04

Polymorphism

এক নাম, ভিন্ন রূপ

Use Cases

  • Android apps
  • Websites (backend system)
  • Desktop applications
  • Banking & financial systems
  • Large enterprise software

Golden Rules of a Java Program

প্রতিটি Java প্রোগ্রামের কিছু বাঁধাধরা নিয়ম আছে — এগুলো ভুলে গেলে কোড কম্পাইলই হবে না।

1. Every application begins with a class, and the class name must match the file name.
2. Every line of code that runs must be inside a class. Class names start with an uppercase letter.
3. Java is case-sensitive — myClass and Myclass are treated as completely different names.
4. The main() method is required in every Java program — this is where execution starts.
Main.java — Hello World
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
Output Hello World!

Data Types & Identifiers

Java-তে ডেটা টাইপ দুই ভাগে ভাগ করা যায়: primitive (সরাসরি মান রাখে) আর non-primitive (রেফারেন্স রাখে)। আর identifier হলো ভ্যারিয়েবল/клас/মেথডের নাম।

"7" vs '7' vs 7

LiteralTypeMeaning
"7"StringSequence of characters
'7'charSingle character
7intNumeric integer value

Primitive Types

  • byte, short, int, long, float, double, char, boolean
  • Stores value directly
  • Fixed size, faster
  • No methods, cannot be null

Non-Primitive Types

  • String, Array, Class, Object, Interface
  • Stores a reference
  • Size depends on object, slightly slower
  • Has methods, can be null

Identifier Rules — নিয়মগুলো

Identifier হলো ভ্যারিয়েবল, মেথড, ক্লাস, প্যাকেজ ইত্যাদির নাম — ইউজার নিজে ঠিক করে দেয়।

  • Start character: letter (a-z, A-Z), $, or underscore _ — e.g. myName, _count, $price
  • No keywords: can't be a reserved word like class, if, for, public
  • Case-sensitive: myVariable ≠ MyVariable
  • No special characters: no @, #, ! etc.
  • Cannot start with a digit: 123value ❌ invalid

Variables in Java

ভ্যারিয়েবল কোথায় ঘোষণা (declare) করা হচ্ছে তার উপর ভিত্তি করে তিন প্রকার: Local, Instance, আর Static।

Local

Declared inside a method or block. Scope limited to that block.

মেথডের ভেতরে ঘোষিত, শুধু সেখানেই ব্যবহারযোগ্য।

Instance

Declared inside a class, outside any method. Belongs to an object.

ক্লাসের ভেতরে, মেথডের বাইরে — প্রতিটি অবজেক্টের নিজস্ব কপি থাকে।

Static / Class

Declared with the static keyword. Belongs to the class, not one object.

static কিওয়ার্ড দিয়ে ঘোষিত — ক্লাসের সব অবজেক্ট একসাথে শেয়ার করে।

Main.java — local variable
public class Main {
    public void myMethod() {
        int x = 5; // local variable
        System.out.println(x);
    }
}
Main.java — instance variable
public class Main {
    int x = 10; // instance variable
    public void myMethod() {
        System.out.println(x);
    }
}
Main.java — static variable
public class Main {
    static int x = 20; // static/class variable
    public static void myMethod() {
        System.out.println(x);
    }
}

Object in Java

Object হলো ক্লাসের একটি বাস্তব রূপ (instance)। new কিওয়ার্ড দিয়ে অবজেক্ট তৈরি করা হয়।

Syntax:
ClassName objectName = new ClassName();
objectName.variable = value;

Problem: Create a Box class with height and width. Create an object and display the info.

Box.java
class Box {
    double height;
    double width;
}

public class Main {
    public static void main(String[] args) {
        Box myBox = new Box();
        myBox.height = 7.3;
        myBox.width = 9.4;
        System.out.println("Height is = " + myBox.height);
        System.out.println("Width is = " + myBox.width);

Methods in Java

Method হলো কতগুলো statement-এর সমষ্টি যেগুলো একসাথে একটি নির্দিষ্ট কাজ করে। প্রতিটি method অবশ্যই একটি class-এর ভেতরে থাকতে হবে।

Standard Library Method

  • println()
  • nextInt()
  • sqrt() etc.

User-Defined Method

  • Created by the programmer to perform a custom task
Syntax: modifier returnType methodName(parameterList) { // body }

Without Return Type (void)

Main.java
public class Main {
    public static void sum(int a, int b) {
        int result = a + b;
        System.out.println("The sum is: " + result);
    }
    public static void main(String[] args) {
        sum(5, 10);
    }
}

With Return Type

Main.java
public class Main {
    public static int sum(int a, int b) {
        return a + b;
    }
    public static void main(String[] args) {
        int result = sum(5, 10);
        System.out.println("The sum is: " + result);
    }
}

Method Overloading

একই ক্লাসে একই নামের একাধিক মেথড থাকলে, কিন্তু প্যারামিটার আলাদা হলে, তাকে method overloading বলে। এতে প্রোগ্রামের readability বাড়ে।

Two ways to overload a method:
1. By changing the number of arguments (প্যারামিটারের সংখ্যা পরিবর্তন করে)
2. By changing the data type of arguments (প্যারামিটারের ডেটা টাইপ পরিবর্তন করে)

1. Changing Number of Arguments

OverloadDemo.java
public class OverloadDemo {
    public void sum(int a, int b) {
        System.out.println(a + b);
    }
    public void sum(int a, int b, int c) {
        System.out.println(a + b + c);
    }
    public static void main(String[] args) {
        OverloadDemo obj = new OverloadDemo();
        obj.sum(5, 10);
        obj.sum(10, 20, 30);
    }
}

2. Changing Data Type

OverloadDemo2.java
public class OverloadDemo2 {
    public void sum(int a, int b) {
        System.out.println(a + b);
    }
    public void sum(double a, double b) {
        System.out.println(a + b);
    }
    public static void main(String[] args) {
        OverloadDemo2 obj = new OverloadDemo2();
        obj.sum(5, 10);
        obj.sum(5.5, 6.25);
    }
}

Constructors

Constructor একটি বিশেষ মেথড যা অবজেক্ট তৈরি হওয়ার সময় স্বয়ংক্রিয়ভাবে কল হয়ে অবজেক্টকে initialize করে।

  • A constructor is a special method used to initialize an object
  • Constructor name must match the class name
  • It cannot have a return type (not even void)
  • All classes have a constructor by default if not written explicitly

Default Constructor

No-argument constructor. Automatically sets initial or default values.

Parameterized Constructor

Takes arguments to set custom initial states directly upon birth.

Constructor Overloading Example

Car.java
public class Car {
    int x; int y;

    // Default Constructor (No arguments)
    public Car() {
        this.x = 5; this.y = 10;
    }

    // Parameterized Constructor
    public Car(int a, int b) {
        this.x = a; this.y = b;
    }

    public static void main(String[] args) {
        Car obj1 = new Car(); // Calls default
        Car obj2 = new Car(20, 30); // Calls parameterized
        
        System.out.println("Car1 = " + obj1.x + ", " + obj1.y);
        System.out.println("Car2 = " + obj2.x + ", " + obj2.y);
    }
}

Method vs Constructor

পরীক্ষায় প্রায়ই এই পার্থক্যটি জিজ্ঞেস করা হয় — নিচের টেবিলটি ভালোভাবে মুখস্থ রাখো।

Java Method

  • Used to expose the behavior of an object.
  • Must have a return type (like void, int, etc.).
  • Method name may or may not match the class name.
  • Invoked explicitly (যেমন: obj.display()).
  • Conventionally starts with a lowercase letter.

Java Constructor

  • Used to initialize the state of an object.
  • Must NOT have a return type (not even void).
  • Constructor name must be identical to the class name.
  • Invoked implicitly during object creation via new.
  • Starts with an uppercase letter (matches class name).

The `super` Keyword

super কিওয়ার্ড দিয়ে চাইল্ড ক্লাস থেকে সরাসরি তার immediate parent (ঠিক উপরের অভিভাবক) ক্লাসের প্রোপার্টি অ্যাক্সেস করা যায়।

Three Key Uses of super:
1. super.variableName — Parent class-এর instance variable-কে নির্দেশ করতে।
2. super.methodName() — Parent class-এর মেথডকে ডাকতে (invoke করতে)।
3. super() — Parent class-এর constructor-কে কল করতে।
Vehicle.java — Using super Keyword
class Vehicle {
    int speed = 50;
    
    public void display() {
        System.out.println("Hello polapains!");
    }
}

class Car extends Vehicle {
    int speed = 100;
    
    @Override
    public void display() {
      System.out.println("Hello Rakin");
        System.out.println(super.speed);   // i. Immediate parent variable (50)
        System.out.println(speed);         // Child variable (100)
        super.display();                   // ii. Invoke parent method
    }
    
    public static void main(String[] args) {
        Car obj = new Car();
        obj.display();
    }
}
Output Hello Rakin

13

Encapsulation

ভ্যারিয়েবল private রেখে, পাবলিক set ও get মেথড দিয়ে সেই ভ্যারিয়েবলের মান পড়া/লেখার নিয়মকে Encapsulation বলে — অনেকটা ক্যাপসুলের মতো ভেতরের জিনিস মুড়ে রাখা।

1. Declare class variables/attributes as private
2. Provide public set and get methods to access & update the private variable
3. The set method sets the value (writes)
4. The get method returns the value (reads)
Person.java — encapsulation
public class Person {
    private String name;

    // set method (writes data)
    public void setName(String name) {
        this.name = name;
    }
    // get method (reads data)
    public String getName() {
        return name;
    }
}

public class Main {
    public static void main(String[] args) {
        Person obj = new Person();
        obj.setName("Rakin");
        System.out.println(obj.getName());
    }
}
Output Rakin

Abstraction & Polymorphism

Abstraction

ব্যবহারকারীর কাছ থেকে অপ্রয়োজনীয় তথ্য লুকিয়ে রাখা, যাতে অ্যাপ্লিকেশনটি ব্যবহার করা সহজ হয়। শুধু প্রয়োজনীয় বৈশিষ্ট্যগুলোই দেখানো হয়।

Hiding unnecessary data from the user and making the application user-friendly. Hides implementation details, shows only essential features.

Polymorphism

এক নাম, ভিন্ন ভিন্ন পরিস্থিতিতে ভিন্ন আচরণ — এটিই Polymorphism ("বহুরূপতা")।

1. Method Overloading

একই ক্লাসে (Same class), একই নামে (Same name) কয়েকটা মেথড। মেথডগুলোর নাম এক হলেও প্যারামিটারের সংখ্যা ভিন্ন অথবা ডেটা টাইপ ভিন্ন হতে হবে।

2. Method Overriding

এজন্য একাধিক ক্লাস (More than 1 class) লাগবে যেখানে IS-A relationship বিদ্যমান। প্যারেন্ট ও চাইল্ড ক্লাসের মেথডের নাম এবং প্যারামিটার একদম হুবহু সেম হতে হবে।

Method Overriding — Example

চাইল্ড ক্লাস (Rakin) প্যারেন্ট ক্লাস (Student)-এর ইনহেরিট করা run() মেথডের আচরণ সম্পূর্ণ নিজের মতো করে বদলে নিয়েছে। @Override কিওয়ার্ড দিয়ে এটি নির্দেশ করা হয়।

Main.java — Overriding
class Student {
    public void run() {
        System.out.println("Hello person");
    }
}

class Rakin extends Student {
    @Override
    public void run() {
        System.out.println("Hello Rakin");
    }
}

public class Main {
    public static void main(String[] args) {
        Rakin obj = new Rakin();
        obj.run(); // Runs overridden version
    }
}
Output Hello Rakin

UML Diagram Assignment (Programming Tree)

নিচের ক্লাসের ছবির ডায়াগ্রামটি (UML) ভালোভাবে লক্ষ্য করো। এটি একটি ৩-স্তরের Multilevel Inheritance রিলেশনশিপ ম্যাপ করে।

Programming
+ languageName : String
+ creator : String
+ setData(String, String) : void
+ display() : void
◀ extends ◀
Java
+ version : double
+ setJavaData(double) : void
+ display() : void
◀ extends ◀
Python
+ paradigm : String
+ setPythonData(String) : void
+ display() : void

Question: Convert the above class diagram into appropriate Java code. Create one object of the Python class inside the Main method, implement all data sets, and verify the expected output.

Programming.java — Level 1 Superclass
class Programming {
    public String languageName;
    public String creator;

    public void setData(String languageName, String creator) {
        this.languageName = languageName;
        this.creator = creator;
    }

    public void display() {
        System.out.println("Basic programming");
    }
}
Java.java — Level 2 Intermediate Subclass
class Java extends Programming {
    public double version;

    public void setJavaData(double version) {
        this.version = version;
    }

    @Override
    public void display() {
        super.display(); // Calls parent Programming.display()
        System.out.println("Java programming");
    }
}
Python.java — Level 3 Child Subclass
class Python extends Java {
    public String paradigm;

    public void setPythonData(String paradigm) {
        this.paradigm = paradigm;
    }

    @Override
    public void display() {
        super.display(); // Calls parent Java.display()
        System.out.println("python programming");
    }
}
Main.java — Execution Driver Block
public class Main {
    public static void main(String[] args) {
        // Instantiate a single bottom-level child object
        Python obj = new Python();
        
        // Accessing inherited methods across different tree levels
        obj.setData("python", "Guido van Rossum");
        obj.setJavaData(17.0);
        obj.setPythonData("oop");
        
        // Triggers the overridden chain execution
        obj.display();
    }
}
Expected System Output:
Basic programming
Java programming
python programming
💡 কেন এই ক্রমানুসারে আউটপুট এলো?
যখন আমরা obj.display() কল করি, তখন চেইনের সবার নিচে থাকা Python ক্লাসের মেথডটি চালু হয়। তার ভেতরে super.display() থাকার কারণে সে তার প্যারেন্ট Java-র মেথডকে রান করায়। Java-র মেথডটি আবার তার নিজস্ব super.display() দিয়ে একদম টপ-লেভেলের Programming ক্লাসের মেথডকে সচল করে। ফলে আউটপুট চেইনটি উপর থেকে নিচে নিখুঁতভাবে প্রিন্ট হয়।
