What is Java?

জাভা হলো একটি high-level, object-oriented প্রোগ্রামিং ভাষা। এটি ক্লাস ও অবজেক্টের উপর ভিত্তি করে তৈরি, তাই একে object-oriented programming (OOP) ভাষা বলা হয়।

Java is a high-level, object-oriented programming language. It's called "object-oriented" because it's built around classes and objects, and supports the four core OOP principles:

01

Inheritance

বৈশিষ্ট্য উত্তরাধিকার সূত্রে পাওয়া

02

Abstraction

অপ্রয়োজনীয় তথ্য লুকানো

03

Encapsulation

ডেটা ও কোড এক ইউনিটে বাঁধা

04

Polymorphism

এক নাম, ভিন্ন রূপ

Use Cases

  • Android apps
  • Websites (backend system)
  • Desktop applications
  • Banking & financial systems
  • Large enterprise software

Golden Rules of a Java Program

প্রতিটি Java প্রোগ্রামের কিছু বাঁধাধরা নিয়ম আছে — এগুলো ভুলে গেলে কোড কম্পাইলই হবে না।

1. Every application begins with a class, and the class name must match the file name.
2. Every line of code that runs must be inside a class. Class names start with an uppercase letter.
3. Java is case-sensitive — myClass and Myclass are treated as completely different names.
4. The main() method is required in every Java program — this is where execution starts.
Main.java — Hello World
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
Output Hello World!

Data Types & Identifiers

Java-তে ডেটা টাইপ দুই ভাগে ভাগ করা যায়: primitive (সরাসরি মান রাখে) আর non-primitive (রেফারেন্স রাখে)। আর identifier হলো ভ্যারিয়েবল/ক্লাস/মেথডের নাম।

"7" vs '7' vs 7

LiteralTypeMeaning
"7"StringSequence of characters
'7'charSingle character
7intNumeric integer value

Primitive Types

  • byte, short, int, long, float, double, char, boolean
  • Stores value directly
  • Fixed size, faster
  • No methods, cannot be null

Non-Primitive Types

  • String, Array, Class, Object, Interface
  • Stores a reference
  • Size depends on object, slightly slower
  • Has methods, can be null

Identifier Rules — নিয়মগুলো

Identifier হলো ভ্যারিয়েবল, মেথড, ক্লাস, প্যাকেজ ইত্যাদির নাম — ইউজার নিজে ঠিক করে দেয়।

  • Start character: letter (a-z, A-Z), $, or underscore _ — e.g. myName, _count, $price
  • No keywords: can't be a reserved word like class, if, for, public
  • Case-sensitive: myVariable ≠ MyVariable
  • No special characters: no @, #, ! etc.
  • Cannot start with a digit: 123value ❌ invalid

Variables in Java

ভ্যারিয়েবল কোথায় ঘোষণা (declare) করা হচ্ছে তার উপর ভিত্তি করে তিন প্রকার: Local, Instance, আর Static।

Local

Declared inside a method or block. Scope limited to that block.

মেথডের ভেতরে ঘোষিত, শুধু সেখানেই ব্যবহারযোগ্য।

Instance

Declared inside a class, outside any method. Belongs to an object.

ক্লাসের ভেতরে, মেথডের বাইরে — প্রতিটি অবজেক্টের নিজস্ব কপি থাকে।

Static / Class

Declared with the static keyword. Belongs to the class, not one object.

static কিওয়ার্ড দিয়ে ঘোষিত — ক্লাসের সব অবজেক্ট একসাথে শেয়ার করে।

Main.java — local variable
public class Main {
    public void arik() {
        int x = 5;
        System.out.println(x);
    }
}
Main.java — instance variable
public class Main {
    int x = 10;
    public void arik() {
        System.out.println(x);
    }
}
Main.java — static variable
public class Main {
    static int x = 20;
    public static void arik() {
        System.out.println(x);
    }
}

Methods in Java

Method হলো কতগুলো statement-এর সমষ্টি যেগুলো একসাথে একটি নির্দিষ্ট কাজ করে। প্রতিটি method অবশ্যই একটি class-এর ভেতরে থাকতে হবে।

Standard Library Method

  • println()
  • nextInt()
  • sqrt() etc.

User-Defined Method

  • Created by the programmer to perform a custom task
Syntax: modifier returnType methodName(parameterList) { // body }

Without Return Type (void)

Arik.java
public class Arik {
    public static void sum(int a, int b) {
        int result = a + b;
        System.out.println("The sum is: " + result);
    }
    public static void main(String[] args) {
        sum(5, 10);
    }
}

With Return Type

Abrar.java
public class Abrar {
    public static int sum(int a, int b) {
        return a + b;
    }
    public static void main(String[] args) {
        int result = sum(5, 10);
        System.out.println("The sum is: " + result);
    }
}

Calling a Method via an Object

Arik.java — max()
public class Arik {
    public int max(int x, int y) {
        if (x > y) { return x; }
        else { return y; }
    }
    public static void main(String[] args) {
        Arik obj = new Arik();
        int big = obj.max(10, 5);
        System.out.println("The max is: " + big);
    }

Method Overloading

একই ক্লাসে একই নামের একাধিক মেথড থাকলে, কিন্তু প্যারামিটার আলাদা হলে, তাকে method overloading বলে। এতে প্রোগ্রামের readability বাড়ে।

Two ways to overload a method:
1. By changing the number of arguments
2. By changing the data type of arguments

1. Changing Number of Arguments

Arik.java
public class Arik {
    public void sum(int a, int b) {
        System.out.println(a + b);
    }
    public void sum(int a, int b, int c) {
        System.out.println(a + b + c);
    }
    public static void main(String[] args) {
        Arik obj = new Arik();
        obj.sum(5, 10);
        obj.sum(10, 20, 30);
    }
}

2. Changing Data Type

Abrar.java
public class Abrar {
    public void sum(int a, int b) {
        System.out.println(a + b);
    }
    public void sum(double a, double b) {
        System.out.println(a + b);
    }
    public static void main(String[] args) {
        Abrar obj2 = new Abrar();
        obj2.sum(5, 10);
        obj2.sum(5.100, 6.25);
    }
}

Constructors

Constructor একটি বিশেষ মেথড যা অবজেক্ট তৈরি হওয়ার সময় স্বয়ংক্রিয়ভাবে কল হয়ে অবজেক্টকে initialize করে।

  • A constructor is a special method used to initialize an object
  • Constructor name must match the class name
  • It cannot have a return type (not even void)
  • All classes have a constructor by default

Default Constructor

No-argument constructor. Automatically called after object creation.

Parameterized Constructor

Takes arguments to set initial values directly.

Default Constructor Example

Box.java
public class Box {
    double H;
    double W;
    public Box() {
        this.H = 5;
        this.W = 10;
    }
    public static void main(String[] args) {
        Box obj = new Box();
        System.out.println("The height is: " + obj.H);
        System.out.println("The width is: " + obj.W);
    }
}

Parameterized Constructor Example

Laptop.java
public class Laptop {
    int x;
    int y;
    public Laptop(int a, int b) {
        this.x = a;
        this.y = b;
    }
    public static void main(String[] args) {
        Laptop box = new Laptop(5, 10);
        System.out.println(box.x);
        System.out.println(box.y);
    }
}

Constructor Overloading

একই ক্লাসে একাধিক constructor থাকতে পারে, প্রতিটির প্যারামিটার লিস্ট আলাদা — একে বলে constructor overloading।

Car.java — multiple constructors
public class Car {
    int x;
    int y;
    public Car() {
        this.x = 5; this.y = 10;
    }
    public Car(int a, int b) {
        this.x = a; this.y = b;
    }
    public static void main(String[] args) {
        Car obj1 = new Car();
        Car obj2 = new Car(20, 30);
        Car obj3 = new Car(100, 200);
        System.out.println("Car1 = " + obj1.x + obj1.y);
        System.out.println("Car2 = " + obj2.x + obj2.y);
        System.out.println("Car3 = " + obj3.x + obj3.y);
    }
}

Method vs Constructor

পরীক্ষায় প্রায়ই এই পার্থক্যটি জিজ্ঞেস করা হয় — নিচের টেবিলটি ভালোভাবে মুখস্থ রাখো।

Java Method

  • Used to expose the behavior of an object
  • Must have a return type or not (i.e. can be void)
  • Method name may or may not match the class name
  • Invoked explicitly
  • Starts with a lowercase letter

Java Constructor

  • Used to initialize the state of an object
  • Must NOT have a return type
  • Constructor name must be same as the class name
  • Invoked implicitly
  • Starts with an uppercase letter

12

Encapsulation

ভ্যারিয়েবল private রেখে, পাবলিক set ও get মেথড দিয়ে সেই ভ্যারিয়েবলের মান পড়া/লেখার নিয়মকে Encapsulation বলে — অনেকটা ক্যাপসুলের মতো ভেতরের জিনিস মুড়ে রাখা।

1. Declare class variables/attributes as private
2. Provide public set and get methods to access & update the private variable
3. The set method sets the value (writes)
4. The get method returns the value (reads)

Set Method

  • At least one parameter
  • Return type void
  • Sets / writes the value

Get Method

  • No parameter
  • Returns the variable's value
Person.java — encapsulation
public class Person {
    private String name;

    // set method
    public void setName(String name) {
        this.name = name;
    }
    // get method
    public String getName() {
        return name;
    }
}

public class Arik {
    public static void main(String[] args) {
        Person obj = new Person();
        obj.setName("Rakin");
        System.out.println(obj.getName());
    }
}
Output Rakin

Abstraction & Polymorphism

Abstraction

ব্যবহারকারীর কাছ থেকে অপ্রয়োজনীয় তথ্য লুকিয়ে রাখা, যাতে অ্যাপ্লিকেশনটি ব্যবহার করা সহজ হয়। শুধু প্রয়োজনীয় বৈশিষ্ট্যগুলোই দেখানো হয়।

Hiding unnecessary data from the user and making the application user-friendly. Hides implementation details, shows only essential features.

Polymorphism

এক নাম, ভিন্ন ভিন্ন পরিস্থিতিতে ভিন্ন আচরণ — একেই বলে Polymorphism ("বহুরূপতা")।

The ability of an object to take many forms.

Real-life example — Arik:
In a shopping mall → behaves like a customer
On a bus → behaves like a passenger
At school → behaves like a student
At home → behaves like a son

প্রতিটি shape-এর নিজস্ব Draw() আছে, কিন্তু মেথডের নাম একই — এটাই polymorphism।

Two Types of Polymorphism

1. Method Overloading

Same class, same method name, but different number/type of parameters.

একই ক্লাসে, একই নামে কয়েকটা method — কিন্তু parameter সংখ্যা বা data type ভিন্ন হবে।

2. Method Overriding

Needs more than 1 class (parent-child). Same method name, same parameters, IS-A relationship.

একাধিক ক্লাস লাগে (parent-child) — child class parent-এর মেথডকে নতুনভাবে লেখে (redefine করে)।

Method Overriding — Example

Child class (Arik) parent class (Student)-এর run() মেথডকে নিজের মতো করে আবার লিখেছে — একে বলে method overriding। @Override annotation দিয়ে এটি বোঝানো হয়।

Arik.java — @Override
public class Student {
    public void run() {
        System.out.println("Hello person");
    }
}

public class Arik extends Student {
    @Override
    public void run() {
        System.out.println("Hello Arik");
    }
    public static void main(String[] args) {
        Arik obj = new Arik();
        obj.run();
    }
}
Output Hello Arik

Inheritance

একটি object যখন আরেকটি object-এর সব বৈশিষ্ট্য ও আচরণ অর্জন করে, তখন তাকে Inheritance বলে। যে ক্লাস থেকে বৈশিষ্ট্য পাওয়া যায় তাকে parent/super/base class বলে, আর যে ক্লাস উত্তরাধিকার পায় তাকে child/sub/derived class বলে।

  • Inherited class = parent / super / base class
  • Inheriting class = child / sub / derived class
  • Keyword used: extends
  • Represents the IS-A relationship
Person (super class)
▲
Student (sub class)

Student is a Person — এভাবেই IS-A সম্পর্ক বোঝা যায়।

class Person {

public class Animal {

    // Body — OX IS-A Animal

The super Keyword

super কিওয়ার্ড দিয়ে সরাসরি parent (immediate) class-এর জিনিসপত্র অ্যাক্সেস করা যায়।

  • super.variableName — immediate parent class-এর instance variable-কে refer করে
  • super.method() — immediate parent class-এর method invoke করে
  • super() — immediate parent class-এর constructor invoke করে
Car.java — using super
public class Vehicle {
    int speed = 50;
    public void display() {
        System.out.println("Hello polapains!");
    }
}

class Car extends Vehicle {
    int speed = 100;
    public void display() {
        System.out.println("Hello Arik");
        System.out.println(super.speed);   // parent's speed
        System.out.println(speed);         // child's own speed
        super.display();               // calls Vehicle's display()
    }
    public static void main(String[] args) {
        Car obj = new Car();
        obj.display();
    }
}
Output Hello Arik → 50 → 100 → Hello polapains!

এখানে super.speed দিয়ে parent-এর speed = 50 পাওয়া যাচ্ছে, আর সাধারণ speed লিখলে child-এর নিজস্ব speed = 100 পাওয়া যায়। শেষে super.display() parent-এর display() মেথডকে কল করেছে।

🏆 Capstone — Multilevel Inheritance + Overriding + super

এই সমস্যাটি সবচেয়ে গুরুত্বপূর্ণ — এখানে multilevel inheritance (Programming → Java → Python), method overriding, আর super.display() — সবগুলো একসাথে ব্যবহার হয়েছে। মন দিয়ে বোঝো!

Programming.java
class Programming {
    public String languageName;
    public String creator;

    public void setData(String languageName, String creator) {
        this.languageName = languageName;
        this.creator = creator;
    }
    public void display() {
        System.out.println("Basic programming");
    }
}
Java.java
class Java extends Programming {
    public double version;

    public void setJavaData(double version) {
        this.version = version;
    }
    @Override
    public void display() {
        super.display();
        System.out.println("Java programming");
    }
}
Python.java
class Python extends Java {
    public String paradigm;

    public void setPythonData(String paradigm) {
        this.paradigm = paradigm;
    }
    @Override
    public void display() {
        super.display();
        System.out.println("python programming");
    }
}
Main.java
public class Main {
    public static void main(String[] args) {
        Python obj = new Python();
        obj.setData("python", "Guido van Rossum");
        obj.setJavaData(17.0);
        obj.setPythonData("oop");
        obj.display();
    }
}
Output Basic programming → Java programming → python programming
কেন এমন output হলো?
যখন obj.display() কল হয়, Python ক্লাসের display() রান হয়। সেখানে প্রথমেই super.display() কল হওয়ায় Java ক্লাসের display() রান হয় — যেটা আবার নিজের ভিতরে super.display() দিয়ে Programming ক্লাসের display()-কে কল করে। এভাবে চেইন ধরে উপর থেকে নিচে সব display() একে একে প্রিন্ট হয়: আগে Basic programming, তারপর Java programming, শেষে python programming।
